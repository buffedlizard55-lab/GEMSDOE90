What this file is (and why it should beat 0.2778)

The incumbent h33-h33-2-b2 (CLAIM 0.2778, owner-reported — no organizer receipt on file) is the H19-5 support thinned to 2.8 px-spaced unit dots with a >2 px catalogue collar (37,654 dots, byte-identical rebuild verified in this repo). It wins because sparse unit dots maximise unique 300 m-kernel coverage per unit of penalised mass, it puts zero mass on the catalogue (scored truth is faults missing from the catalogue), and ~38–44k dots is the empirical budget sweet spot. But every later repo candidate only re-arranges dots on that same support (measured headroom <0.010), so the support is the ceiling. This file instead builds a new support: a fold-clean learned fault-ness surface over 51 label-agnostic layers (19 competition bands + magnetic/gravity/basement derivatives + USGS-3DEP lidar-scarp stack + GeoDAWN radiometrics; no catalogue-derived feature), then applies the incumbent's proven emission (2.8 px Poisson unit dots, dcatalogue>2 px, zero catalogue mass).
