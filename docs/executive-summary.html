How to submit a validated TIFF

STOP: no approved file is available. This guide does not authorize an existing experimental file for upload.
  1. Generate an independent candidate in an assigned lane using the shared cached features and writer. Never rename a previous submission to claim novelty.
  2. Require per-feature leakage canaries, buffered whole-segment hide-and-recover, visible-only catalogue features and pixel-exact visible-fault masking. Compare pooled HOLDOUT-DTI with the current baseline, evaluator version, positive count and segment-bootstrap confidence interval.
  3. Compare the pre-placement surface and final dots against the complete registry. Stop on rank correlation above 0.90 or directional overlap above 70% within 3 pixels.
  4. Reopen the actual TIFF and run python -m src.validate CANDIDATE.tif SAMPLE.tif --catalogue EXISTING_FAULTS.tif --zeros-outside for an all-zero-outside encoding. Require single band, matching CRS/shape/transform and finite in-footprint values in [0,1]. Do not blindly clip broken predictions.
  5. Only a separate selector may promote a candidate that beats the verified holdout best. Confirm the actual weekly quota from the submission page; the current quota is unknown here.
  6. Download the selected private artifact, verify its SHA-256 against its run card, then choose that single .tif on the official submission page. Enter its unique name and a factual note of at most 140 characters. Uploading spends a slot; downloading does not.
  7. Store the organizer receipt, file hash and timestamp. Only receipt-backed results are ORGANIZER-CONFIRMED. A local validation pass does not guarantee organizer acceptance or performance.

There is no automatic organizer upload in this project. The public site deliberately does not redistribute competition rasters.
